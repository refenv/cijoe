core.tools_check
~~~~~~~~~~~~~~~~

.. automodule:: cijoe.core.scripts.tools_check
   :members:

CLI arguments
-------------

* ``--tools TOOLS``

  Comma-separated tools to check; default: those '[tools]' describes. (default: None)

* ``--target_name TARGET_NAME``

  The transport of the target to check; default: cijoe's. (default: None)

* ``--refresh REFRESH``

  Ask the target even about tools its facts already describe. (default: false)
