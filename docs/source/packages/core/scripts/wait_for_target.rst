core.wait_for_target
~~~~~~~~~~~~~~~~~~~~

.. automodule:: cijoe.core.scripts.wait_for_target
   :members:

CLI arguments
-------------

* ``--state {down,up}``

  Desired target state to wait for: 'down' or 'up'. Default: up. (default: up)

* ``--timeout TIMEOUT``

  Maximum seconds to wait for the desired state. (default: 60)
